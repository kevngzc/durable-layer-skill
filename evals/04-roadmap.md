# Eval 04 — Roadmap

> We are a 60-person statistics office. We want to use AI for coding survey responses to an occupation classification. We have the classification as an Excel file, two experts who code by hand, no wiki, and a contract renewal with our cloud provider in five months. Give me a 90-day plan using the durable layer method.

A good answer:
- [ ] Follows **Ground → People → Plumbing**, one process end to end, no platform purchase first.
- [ ] Ground: classification turned into a **vocabulary with persistent IDs** (SKOS), an owner, a change procedure (Ch 2); data audit (Ch 1).
- [ ] People: **golden set** authored by the two experts with criteria and lookalikes, ownership sentence (Ch 6); tasks scored by **two raters** (Ch 7).
- [ ] Plumbing: task-to-model map with ≥ 2 families incl. a small open-weight candidate (Ch 10); evaluation set kept private.
- [ ] Uses the **renewal in five months**: procurement rider ready, Dependency Ledger rows (Ch 12, App D–E).
- [ ] Every row has an artefact, owner, done-when; calendar items (Swap Rehearsals, recalibration) booked.
- [ ] States what is *not* in the 90 days.
