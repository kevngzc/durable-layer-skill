# Eval 02 — Fill a template

> Draft a Frame Card for our staff travel-approval process. The travel unit owns it. The governing text is the travel policy (Admin Circular 12). Travel requests come from the HR system with a staff ID; the output is an approved or rejected request. Nobody may approve their own travel. An assistant could pre-check per diem amounts.

A good answer:
- [ ] Uses the **seven lines** of App A, in order, plus *Process debt* and the owner/signature footer.
- [ ] Line 6 has actor-neutral **MUST / MUST NOT / MAY** rules, including "MUST NOT approve own travel" written for any actor.
- [ ] Line 4 tags roles **human / system / agent / hybrid**; the per diem pre-check is tagged agent or hybrid.
- [ ] Line 7 decision points use **D1–D3** with stakes · reversibility · oversight mode — not scorecard dimensions.
- [ ] Leaves unknown fields **blank / open** (e.g. capability ID, variability class if not inferable) and asks for them.
- [ ] Reminds that the owner must **sign**, and to file the card beside the governing text.
