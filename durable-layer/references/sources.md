# Open standards the durable layer is written in (App G)

Public facts as of the book's 2026 edition. Versions move; when a user's decision depends on a current version, say so and suggest they check the standard's own site.

| Standard | Body · version | Used for |
|:--------|:---------|:-----------|
| **BPMN 2.0.2** / ISO/IEC 19510 | OMG · ISO | Operational flows for repeatable processes (below the Frame Card) |
| **DMN 1.6** | OMG | Decision tables, requirements diagrams, knowledge sources (Ch 9) |
| **CMMN 1.1** | OMG | Knowledge-driven cases that cannot be sequenced |
| **SKOS** | W3C Recommendation | Thesauri and controlled vocabularies with persistent concept IDs (Ch 2) |
| **OCEL 2.0** | RWTH | Object-centric event logs; measuring process debt and volume (D3) |
| **MCP** | Linux Foundation / AAIF | Tool protocol at the gateway; descriptors generated from tool contracts; 12-month deprecation window |
| **A2A 1.0** | Linux Foundation | Agent-to-agent interface across organizational boundaries |
| **ArchiMate exchange format** | The Open Group | Capabilities, roles, processes, data objects in one exchangeable model |
| **GSBPM 5.1 · GAMSO 1.2** | UNECE | Phase model for reporting and statistical process families |
| **FAIR principles** | Wilkinson et al. 2016 | Description of every input and output (D2, Ch 1) |
| **OWASP Top 10 — Agentic 2026 · LLM 2025** | OWASP GenAI Security Project | Threat checklist for the gateway |
| **NIST AI RMF 1.0** | NIST | Govern / Map / Measure / Manage frame for oversight |
| **ISO/IEC 42001:2023** | ISO/IEC | Certifiable AI management system; oversight modes (Annex A.9.4) |
| **EU AI Act, Art. 14** | EU | Human-oversight duties (Ch 7) |
| **UN Principles on Personal Data Protection and Privacy** | UN HLCM 2018 | Gate G1; rider clause 10 (outside the UN system, use the organization's own data-protection regime) |

**Evidence status.** The readiness scorecard adapts the LARA matrix (Li & Ye, 2026, a preprint). Trust-dashboard bands come from practitioner and pilot sources, not peer-reviewed studies. Say so when either is used to justify a decision.

For the full bibliography, point the user to Appendix G of *The Durable Layer*.
