# Fixed vocabulary

Use these terms exactly. English is canonical; when answering in another language, translate the term and give the English in parentheses on first use. French renderings below are **provisional** (the French edition is not yet written).

| Term | Meaning | FR (provisional) |
|---|---|---|
| **durable layer** | What the organization owns and that every future tool reads: governed data, vocabulary, wiki, rules and tests, Frame Cards, expertise, roles, policies, decision tables, tool contracts, logs | couche durable |
| **replaceable layer** | What is rented and swapped: models, assistants, agent frameworks, interfaces, protocol versions, search indexes, managed services | couche remplaçable |
| **Two-Layer Ledger** | Two-column list, durable vs replaceable (never "Asset Ledger") | registre à deux couches |
| **Dependency Ledger** | One row per replaceable component: exit path, requalification time, notice, last rehearsed | registre des dépendances |
| **Frame Card** | One-page, seven-line, signed description of a process's boundaries | fiche-cadre |
| **normative frame / operational flow** | The owned MUST/MAY/MUST NOT rules vs the sequence a tool happens to follow | cadre normatif / flux opérationnel |
| **process debt** | Known gaps between the Frame Card and current practice | dette de processus |
| **variability class** | Predefined and repeatable, or knowledge-driven case | classe de variabilité |
| **MUST / MAY / MUST NOT** | Actor-neutral rule forms (written for any colleague, system or agent) | DOIT / PEUT / NE DOIT PAS |
| **decision points D1–D3** | Line 7 of a Frame Card — **not** the scorecard dimensions | points de décision D1–D3 |
| **dimensions D1–D6** | Scorecard dimensions (App B) — **not** the Frame Card decision points | dimensions D1–D6 |
| **R1–R4** | Readiness levels: R1 human only · R2 human-led with copilot · R3 agent drafts, human approves every output · R4 agent acts, human audits a sample | niveaux R1–R4 |
| **oversight modes** | in command · in the loop · on the loop | aux commandes · dans la boucle · sur la boucle |
| **floor (F1, F2)** | Non-compensable cap on the level, whatever the mean | plancher |
| **gates G1–G6** | Pass/fail conditions outside the score, required above R1 | portes G1–G6 |
| **golden set** | Expert-authored examples with correct output, criterion and why; test suite and career artefact | jeu d'exemples de référence |
| **scenario suite** | 20–50 cases with known outputs; acceptance test for a decision table | suite de scénarios |
| **five-line policy** | Decision · cues · weights · exceptions · who may deviate | politique en cinq lignes |
| **process-alignment score** | How far a model's reasons weight the cues as the policy does; the acceptance gate | score d'alignement au processus |
| **tool contract** | Five fields: name, inputs, outputs, side-effect class, required authority | contrat d'outil |
| **gateway** | The one door every model and tool call passes through | passerelle |
| **thin adapter** | Protocol adapter one engineer can rewrite in a week; holds no organizational logic | adaptateur fin |
| **kill switch** | Control held by a named duty manager that stops a route, tool, model or everything, without a deployment | coupe-circuit |
| **requalification time** | Days from a retirement notice or swap decision to a qualified replacement | délai de requalification |
| **Swap Rehearsal** | Replacing one model or tool end to end inside one sprint, against the evaluation set; twice a year | répétition de remplacement |
| **demote, never block** | A failed test lowers the deployment mode; the business continues | rétrograder, ne jamais bloquer |
| **partners above a stable line** | Vendors compete on the replaceable layer; the interface belongs to the organization | partenaires au-dessus d'une ligne stable |

Banned in output (the book's house style): leverage, unlock, game-changer, journey, ecosystem, robust, seamless, delve, navigate, landscape.
